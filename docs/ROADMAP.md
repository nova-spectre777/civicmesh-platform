# Roadmap

## v0.1 — Trust + convergence foundation
- Ed25519 alert signing and verification
- Go gateway/store/sync API
- C++ edge relay state engine
- Kotlin offline domain library
- TypeScript offline PWA foundation
- Python partition/convergence simulator
- language-neutral JSON contracts

## v0.2 — Real local transports
- Bluetooth LE discovery/transfer prototype
- Wi-Fi Direct / LAN sync adapter
- QR/file transfer for signed alerts and trust bundles
- bundle chunking, compression and resumable transfer
- replay protection and bundle digests

## v0.3 — Mapping + resources
- offline vector maps
- shelter/clinic/water geospatial index
- capacity and resource freshness indicators
- route-closure overlays
- multilingual accessibility packs

## v0.4 — Trust operations
- signed trust bundles
- key rotation and emergency revocation
- operator roles
- audit logs
- hardware-backed signing integration

## v0.5 — Privacy + abuse resistance
- encrypted help-request contact channel
- rate limiting and abuse scoring
- privacy-preserving aggregate demand views
- Sybil/spam defenses for community observations

## v1.0 target
A field-tested interoperable protocol and reference implementation that can keep trusted public-safety information and basic local coordination available through partial internet outages, without turning emergency communication into a surveillance system.
