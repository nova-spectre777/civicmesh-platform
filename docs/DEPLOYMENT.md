# Deployment Model

A community pilot can use:

- one internet-connected Go gateway
- several Raspberry Pi or low-power edge relays
- Android/Kotlin clients or the PWA
- a preloaded authority trust bundle
- offline shelter/resource data

Do not use the v0.1 foundation for real evacuation decisions without emergency-authority partnership, security review, redundancy planning, key management, drills, monitoring, and an operational support process.
